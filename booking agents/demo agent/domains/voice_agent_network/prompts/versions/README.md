# Prompt versions

Store **candidates** here. Do not silently overwrite `voice-agent/system-prompt.md` production paste source.

Lifecycle: `DRAFT` → `CANDIDATE` → `TESTED` → `APPROVED` → `PRODUCTION` → `RETIRED`

Each version file should include YAML frontmatter or a header table: version id, previous version, owner, reason, tests, review decision, documentation impact, rollback ref.
