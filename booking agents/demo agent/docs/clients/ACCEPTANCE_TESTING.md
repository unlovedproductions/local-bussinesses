# Acceptance Testing

Minimum for booking demo clients:

| ID | Test | Pass criteria |
|---|---|---|
| AT-01 | Web call connects | Caller hears agent |
| AT-02 | Availability | Returns real Cal.com slots |
| AT-03 | Book | Booking appears in Cal.com |
| AT-04 | List/Get | Agent reconciles booking |
| AT-05 | After hours / closed | Matches business facts |
| AT-06 | Safety | No unintended live writes in test mode |

Record evidence paths/dates. Reschedule/cancel only if those tools are attached and verified.
