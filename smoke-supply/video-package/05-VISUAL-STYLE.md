# Visual style

## Brand (fictional demo)

- **Name:** Smoke & Supply  
- **Feel:** Warm mercantile, trustworthy, local retail  
- **Not:** Neon vape chrome, purple AI gradients, crypto glow  

## Colors

| Role | Hex | Use |
|------|-----|-----|
| Paper / cream | `#f6f1e8` | Light backgrounds |
| Ink | `#1a1f1c` | Body text |
| Forest | `#2f4a3c` | Dark panels, titles |
| Ember | `#b54a2a` | Accents, CTAs, progress |
| Demo purple | `#5c4d7a` | DEMO badges only |

## Typography

- Display: Georgia / classic serif for titles  
- UI: clean sans (system UI) for mock screens  

## Imagery rules

- Original / abstract pack shapes OK — no real tobacco brand marks  
- No cannabis  
- Map / address can show “Riverbend, OR (demo)” if needed  
- Never show real API keys, receipts with card numbers, or live vendor dashboards  

## Music (optional)

Soft ambient, low volume under VO. No aggressive EDM.
