# Brief — How POS & Inventory Integration Could Work

## Goal

A short explainer a store owner can watch that shows:

1. Customer orders online for pickup  
2. Order flows through an integration layer  
3. POS and inventory update  
4. In-store sale also updates stock  
5. Website syncs  
6. Low-stock + reorder suggestion  
7. Owner dashboard benefit  

## Audience

Independent smoke / tobacco shop owner. Not technical. Skeptical of “software magic.”

## Tone

Calm, professional, concrete. Mercantile / trustworthy — not neon vape-shop hype, not Silicon Valley jargon.

## Format options (any is fine)

- Motion graphics + UI mockups  
- Screen recording of the demo site + VO  
- Animated storyboard slides  
- AI video from this package  

## Deliverable

One MP4 (or equivalent), ~60–120s, with optional burned-in captions.

## Must open / close with

**Open title:** How POS & Inventory Integration Could Work  

**Close:**  
“One connected system can give the owner a clearer picture of inventory and sales.”  
Then: “This demonstration uses simulated data. Connecting a real store requires identifying the POS and inventory software first.”
